# Kit fixtures

Copies of symbol masters of the Silica 1.0 "Amalfi" UI kit, from
[silica-design](https://github.com/silica-os/silica-design) (CC BY-SA 4.0, the Silica
project), made by `cargo xtask sync-kit`. Do not edit: run the tool again.

silica-design commit: `cbf75649b283c289e154407602e19fe2d6ccee9c`

The selected name prefixes are in `_prefixes`; the masters nested in them as symbol instances are copied too.
